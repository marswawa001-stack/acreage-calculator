# Acreage Calculator

A standalone React version of the Acreage Calculator. Use it to convert width/length into land area (acres, hectares, sq ft, etc.) and optionally estimate total land cost from a unit price.

## What it does

- Converts **width × length** into area
- Supports multiple length and area units
- Optional: estimates **total price** from unit price per area unit

## Inputs / Outputs

- Inputs: width, length (with selectable units)
- Output: area (selectable unit)
- Optional inputs: unit price (currency + per-area unit)
- Optional output: total price (selectable currency)

## Links

- Official Online Calculator (Backlink): https://www.calculatorvast.com/acreage-calculator

## Install

```bash
npm install
```

## Run

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Notes

This export aims to be **runnable as a standalone project**. Some site-only features (analytics, ratings, related calculators, etc.) are intentionally omitted.
